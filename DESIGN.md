# Design direction

Reading this as a single-purpose utility for CrossPoint Reader owners, using a compact print-shop and reader-workbench visual language.

Dial: ENERGY 2 / RHYTHM 2 / MOTION 1

- Color: warm paper and dark ink connect the tool to reading; rust marks only the primary action and focus moments.
- Layout: one direct path from explanation to file selection to download keeps the optimizer, not marketing, at the center.
- Typography: Georgia gives the page a bookish character; system sans and monospace are reserved for controls and technical status text.
- Spacing: a compact vertical rhythm keeps the full task visible without making controls feel crowded.
- Surface: one flat, squared panel groups the complete workflow; its offset shadow separates the working surface from the page.
- Motif: paper, ink, and an offset printed edge repeat the physical-reader character without decorative imagery.
